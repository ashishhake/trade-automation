# 📈 Trade Automation (AWS Deployment)

## 🚀 Project Overview
This project is a trading automation system built using Python that implements algorithmic trading strategies, backtesting, and cloud deployment on AWS.

Current Status: 🛠️ Work in Progress (Active Development)

---

## 🎯 Features (Planned & Ongoing)
- Moving Average (MA) Strategy
- RSI Strategy
- Backtesting with historical market data
- Paper trading simulation
- AWS deployment (EC2/Lambda)
- Risk management (stop-loss, position sizing)
- Logging and monitoring

---

## 🧠 Tech Stack
- Python
- Pandas, NumPy
- Git & GitHub (Version Control)
- AWS (Cloud Deployment)
- VS Code

## ⚙️ How to Run (Local)
1. Clone the repository
2. Create virtual environment:
   ```bash
   python -m venv venv
3. Activate venv and install dependencies: 
    pip install -r requirements.txt
4. Run main script: 
    python src/main.py
